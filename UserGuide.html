⚡ 1. 快速上手与路径配置

初次打开本软件时，管理器会自动探查系统常见安装位置（Steam 目录、桌面快捷方式关联路径等）。

1 游戏根目录核验：

观察顶部导航栏正中绿色胶囊状态。若显示 未配置游戏路径 或红色异常圆点，请点击右侧的 “更换” 按钮，选中您的《铁锈战争》游戏本体所在文件夹（必须包含 game-lib.jar 与 preferences.ini）。

2 全量自动加载：

路径验证通过后，管理器将自动完成所有模组、地图与游戏参数的秒级高速扫描，并在首页呈现完整的管理工作区。

💡 提示：若随时手动往游戏文件夹拖入了新的模组或地图，可直接点击顶部右侧的 刷新图标 (⟳) 重新扫描。

📦 2. 单位模组管理 (Units)

全面取代繁琐的在游戏内一级级点开模组面板，支持模组的实时启禁用、搜索过滤与快速归类。

主要操作指南

  • 单个模组切换：点击卡片右下角的开关或启用/禁用药丸按钮，即可直接写入 preferences.ini，生效状态毫秒级持久化。
  • 一键全开 / 一键全关：在模组标签页右上角点击“一键全部启用”或“一键全部禁用”，适合需要快速排查冲突或大换包场景。
  • 视图模式切换：支持 卡片大图模式 (Grid) 与 紧凑高密度清单模式 (List) 自由切换。
  • 关键字搜索与分类筛选：支持按模组英文原名、中文译名、文件名、分类标签搜索，或仅查看“已启用” / “已禁用”模组。
  • 打开外部工坊：若模组附带 Steam 创意工坊 ID，点击卡片上的工坊链接可一键直达 Steam 工坊详情页。

🗺️ 3. 战术地图工坊与出生点序号标绘

本管理器独创了纯 Go 原生 TMX 地图解析与出生点序号渲染引擎，无需安装任何 Python 或外部工具，单程序开箱即用。

特色功能解析

  • 全类型地图识别：不仅支持独立存放在 mods/maps 的单个地图与文件夹地图，还会深度穿透扫描 mods/units 下所有 .rwmod 模组包中附带的内嵌地图。
  • 战术出生点序号自动标绘：自动读取地图内的队伍标记点（Team 1, Team 2, Team 3...），并在地图渲染图层上直接叠加高对比度的战术圆形编号标志。
  • 一键补齐或全量重绘：
    • 点击 “批量生成缩略图”：仅为当前尚无预览图的地图快速补充出生点标注。
    • 点击 “全量强制重绘”：对所有已有地图（含旧的未标记图）进行全量出生点重新计算与重写。
  • 大图灯箱预览 (Lightbox)：点击任意地图缩略图即可呼出全屏高清大图，支持鼠标滚轮缩放、自适应居中与全屏战术研讨。
  • 宿主模组联动激活：对于内嵌在单位模组内的地图，点击弹窗中的 “一键激活宿主模组”，即可连带将对应的武器模组自动启用，确保战局单位不丢失。

🌐 4. 局域网联机预设自动同步

专为局域网联机对战解决“有人缺模组进不去”、“谁启用了变态单位对不上”、“对战版本不一致”等顽疾，构建了严格的客户端-服务端体系。

⚠️ 规则原则：同一个网络/子网集合内，严格只能有 1 个服务端作为房主主机，其余成员均必须作为客户端。若检测到多个服务端，将全面弹出红色仲裁告警并锁定联机启动。

模式职责与使用流程

角色模式 默认状态 核心职责与行为
客户端 (Client) 默认角色 自动监听局域网心跳广播；启动联机前自动向房主查询预设差异；若本地缺少模组/地图，将自动从房主电脑下载补齐，并将启用状态调整得与房主完全相同。
服务端 (Server/房主) 需手动切换 充当本场对战标准源；通过 UDP 广播自身 IP、端口与动态特征哈希；通过内置 HTTP 传输服务为队员提供模组下载；支持接收队员推送的新模组。

主要联机操作说明

  • 切换角色：在顶部右上角或“局域网联机”选项卡中点击 “客户端” 或 “房主服务端” 即可秒切。
  • 动态启动预设感知：管理器持续侦听本地模组状态。即使在游戏中按下 Ctrl+F5 重载模组，管理器也会动态刷新预设特征哈希。
  • 一键同步房主预设：客户端连接到房主后，可在面板中查看预设差异详情（缺失哪些模组、哪几个模组状态不符），点击 “一键同步房主预设” 即可自动完成下载与启用状态对齐。
  • 队员向房主推送模组：队员想推荐自己制作的好玩模组给房主？在“模组”列表点击 “向房主推送”，房主端将收到实时审批弹窗，房主点击“接受”即可自动传送到房主电脑上。
  • 多网卡与虚拟专网绑定：若使用 Tailscale、Radmin VPN、蒲公英 等虚拟局域网联机，请在设置中将“绑定的网络子网”下拉选择为对应的虚拟网卡。

🚀 5. 游戏启动与高刷新率调优 (Launcher)

无需手动摸索复杂的启动命令行参数，所有调优选项均直观可视化配置。

双启动模式介绍

🟢 联机启动 (带预设自动同步)：

联机开黑专用。启动时会自动校验局域网服务端状态；若为客户端则自动拉取房主预设同步；若检测到多房主冲突则阻断启动，保证进房 100% 预设一致。

⚪ 单机启动 (自由独立运行)：

单人战役或脱机测试专用。完全按照本机当前自己的模组启用状态拉起游戏，不检查局域网房主或冲突。

参数与高刷新率调优

  • 电竞高刷新率支持：直写 preferences.ini 内置参数，支持 60Hz / 120Hz / 144Hz / 240Hz+ 电竞高刷屏，告别默认锁帧卡顿。
  • JVM 内存上限调整：可一键拉升至 4096MB / 8192MB，避免大型战役或重度模组轰炸导致 Java 虚拟机内存溢出 (OOM)。
  • 垂直同步与 FPS 帧率显示：可视化开关，直接随游戏启动生效。
  • 队伍单位上限限制：解除游戏内置造兵总人口限制，畅享大规模战役兵海推进。

🔄 6. 双通道智能自更新体系

管理器具备全自动版本侦测与 Windows 在位热替换自升级能力，支持 局域网 P2P 与 GitHub Releases 双通道。

双通道工作原理

  • 局域网 P2P 极速通道 (零流量首选)：在离线对战房或无公网局域网内，只要任意一台电脑（无论是房主还是队员）运行的是新版本，其他电脑打开管理器时就会通过广播信标自动侦测到新版，并以局域网千兆/百兆内网速度直连拉取新版程序完成秒更。
  • GitHub Releases 官方通道 (全球公网备用)：当电脑处于互联网环境时，管理器会自动请求 GitHub 官方仓库获取正式发布版本。
  • Windows 平滑在位热替换：无需繁琐的安装向导或卸载步骤，更新包下载完成后自动在后台替换可执行文件并唤起重启，旧备份自动清理。
🎉 如何触发更新：启动时管理器会在后台静默自检。一旦有新版，顶部导航栏将亮起金色呼吸徽标 “✨ 新版 vX.X.X”，点击即可呼出弹窗一键升级。您也可以随时在“偏好设置”面板中点击“立即检查更新”。

❓ 7. 常见问题与排错指南

Q1：局域网内队员一直显示“搜寻房主中”，找不到房主？

排查要点：

  1. 确认房主是否已经打开管理器，并且顶部状态切换为了 “房主服务端”（双方都为客户端时无法自动配对）。
  2. 若使用了虚拟局域网（如 Tailscale/Radmin），请双方在管理器“偏好设置”中的“选择绑定的网络子网”下拉框中，均选中该虚拟网卡的 IP/网段。
  3. 检查 Windows 防火墙：在弹出的 Windows 防火墙提示中允许本程序的“专用网络”通讯，或暂时关闭防火墙排查。

Q2：弹出“局域网服务端唯一性冲突告警”，无法点击操作？

解决办法：当前局域网中有两台或更多电脑同时切换为了“房主服务端”。只需冲突双方中任一方在弹窗中点击 “一键将本机切换为客户端”，冲突将立即解除，所有功能即可恢复正常。

Q3：地图没有缩略图，或者看不到 1, 2, 3 出生点标记？

解决办法：切换到“地图”选项卡，点击右上角的 “批量生成缩略图” 或 “全量强制重绘”，管理器将全量高速提取 TMX 地图层并自动合成抗锯齿的战术出生点标志。

Q4：在游戏内修改了模组启用状态，管理器能同步吗？

解决办法：完全可以。管理器对 preferences.ini 具有动态感知能力。即便在游戏内按了 Ctrl+F5 重载模组，返回管理器点击刷新或等待几秒心跳，状态即会自动对齐。
